
🌐 Personal Portfolio –

This is my personal portfolio website built with HTML, CSS, and JavaScript.
It showcases my skills, projects, certifications, and contact information in a clean, modern design with smooth transitions and interactive elements.

🚀 Features

Responsive design (mobile & desktop friendly)

Dark / Light theme toggle with local storage

Animated typewriter effect for introduction

Scroll reveal animations for smooth user experience

Interactive particle background in hero section

Projects with GitHub repo links and tech stack tags

Certifications with credential links

Contact form (demo-only, no backend)

Social links (LinkedIn, GitHub, Email, Phone)

📂 Project Structure
├── index.html   # Main portfolio page
├── style.css    # Styling and themes
├── script.js    # Animations & interactivity
├── me.jpeg      # Profile image
├── employee-management.png # Project thumbnail
├── Currency-Converter.png  # Project thumbnail

🛠️ Technologies Used

HTML5 – structure & semantic layout

CSS3 – responsive design, animations, custom themes

JavaScript (Vanilla) – typewriter effect, theme toggle, particles background, form interaction

Google Fonts (Inter) – typography
